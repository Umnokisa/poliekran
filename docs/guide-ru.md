# Полиэкран — инструкция пользователя

Версия 1.4. [English version](guide-en.md)

Полиэкран — надстройка для Microsoft PowerPoint. Она запускает несколько показов одновременно на разных мониторах одного компьютера: на одном экране презентация, на другом электронное расписание, на третьем ещё что-то. Показы продолжают идти, когда за компьютером работают в других программах.

## 1. Что нужно

- Компьютер с Windows 10 или 11 и двумя или более мониторами (подойдут и телевизоры, подключённые как мониторы).
- Microsoft PowerPoint 2013 или новее, включая Microsoft 365.
- .NET Framework 4.6.2 или новее. В Windows 10 и 11 он уже есть.

Права администратора не нужны.

## 2. Установка

1. Закройте PowerPoint.
2. Запустите `Poliekran-1.4.0-setup.exe`.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Установщик не подписан цифровой подписью, поэтому Windows его не узнаёт.
4. Нажмите «Далее», затем «Готово». Можно сразу отметить «Запустить PowerPoint».

Программа ставится в папку `%LOCALAPPDATA%\Programs\Poliekran`. Там же лежат эта инструкция и краткая памятка `README.txt`.

## 3. Где кнопка

Откройте PowerPoint, перейдите на вкладку **«Слайд-шоу»**. Справа появится группа **«Полиэкран»** с одноимённой кнопкой. Нажмите её, откроется панель управления.

Если кнопки нет, смотрите раздел 10.

## 4. Пульт

Сверху вниз:

| Элемент | Что делает |
|---|---|
| Список мониторов | Выбор экрана, на котором пойдёт показ. Строка вида «2: 1920×1080, позиция 1920,0». Основной монитор подписан «основной». |
| «Полный экран» / «Окно» | Режим показа. Используйте «Полный экран». «Окно» — запасной вариант, он менее надёжен. |
| «Синхронизировать с» | Выбор самостоятельного показа или уже запущенного ведущего. Ведомый следует за текущим слайдом ведущего и листается вручную. |
| «Запустить файл…» | Выбрать презентацию и запустить её на выбранном мониторе. |
| «Обновить мониторы» | Перечитать список мониторов, если вы подключили или отключили экран. |
| «Слайды без времени смены листать через» | Сколько секунд держать слайд, у которого в самой презентации не задано время смены. По умолчанию 15 с. «не листать» — ждать, пока перелистнут вручную. |
| «Перезапускать показ, когда файл изменился» | Следить за файлом и показывать новую версию, когда его пересохранят. Нужно для расписаний. |
| Таблица показов | Файл, монитор, текущий слайд, статус и настройки каждого запущенного показа. |
| «< Назад», «Вперёд >» | Перелистнуть слайд в выбранном показе. |
| «Перезапустить» | Запустить выбранный показ заново. |
| «Остановить», «Остановить все» | Остановить выбранный показ или все сразу. |
| «Esc в показе останавливает его» | Разрешить останавливать показ клавишей Esc прямо на экране. Снимите галочку для экранов, которые никто не должен трогать. |

Кнопки «Назад», «Вперёд», «Перезапустить» и «Остановить» действуют на показы, выделенные в таблице. Если показ один, выделять его не нужно.

Пульт можно закрыть крестиком: показы при этом продолжают идти. Вернуть пульт можно той же кнопкой на ленте.

## 5. Как запустить показ на мониторе

1. В списке мониторов выберите нужный экран.
2. Оставьте режим «Полный экран».
3. Выберите время для слайдов без своего времени смены:
   - для информационного экрана или расписания — 10–30 секунд;
   - для обычного доклада, который листают вручную, — «не листать».
4. Если файл будут обновлять, оставьте галочку «Перезапускать показ, когда файл изменился».
5. Нажмите «Запустить файл…» и выберите презентацию.

Показ откроется на выбранном мониторе во весь экран. Повторите для остальных мониторов. Один и тот же файл можно запустить на нескольких экранах.

Показ всегда идёт по кругу, со всеми слайдами. Исходный файл не меняется: программа работает с копией.

### Синхронные показы

Чтобы показывать разные презентации синхронно — например, русскую и английскую версии на отдельных мониторах:

1. Обычным способом запустите ведущую презентацию.
2. Выберите другой монитор и в поле «Синхронизировать с» укажите ведущий показ.
3. Нажмите «Запустить файл…» и выберите ведомую презентацию.
4. При необходимости повторите для других ведомых презентаций.

Ведущий управляет всей группой. Когда его текущий слайд меняется, Полиэкран переводит каждый ведомый на тот же слайд. Ведомые показы листаются вручную, даже если в исходных файлах заданы автоматические времена. Если в ведомой презентации меньше слайдов, при недоступном номере ведущего она показывает первый слайд. При остановке ведущего его ведомые показы тоже останавливаются.

## 6. Электронное расписание

### Как подготовить файл

- Сделайте расписание обычной презентацией PowerPoint: одна страница — один слайд.
- Если страниц несколько, их можно листать автоматически. Либо задайте время в самой презентации («Переходы» → «Время показа слайдов» → «После»), либо выберите интервал в пульте при запуске.
- Положите файл туда, где его удобно править: на тот же компьютер или в общую сетевую папку.
- Не ставьте на файл пароль: PowerPoint остановится и будет его спрашивать.

### Как обновлять

Откройте файл на любом компьютере, поправьте и сохраните. Закрывать его не обязательно. Примерно через 10 секунд экран покажет новую версию сам.

Как это работает. Программа проверяет файл раз в 5 секунд. Когда видит новую версию и убеждается, что запись закончилась, она открывает её, и только после этого подменяет показ. Если новый файл открыть не удалось (например, его ещё копируют), на экране остаётся старое расписание, а программа попробует позже. Если страниц стало меньше, показ начинается с первой.

Пока идёт показ, исходный файл не заблокирован: его можно перезаписать, переименовать или заменить другим с тем же именем.

## 7. Управление идущими показами

### Статусы в таблице

| Статус | Что значит |
|---|---|
| «идёт» | Показ работает. |
| «перезапуск» | Показ запускается или перезапускается, это занимает несколько секунд. |
| «упал, повтор через N с» | Показ закрывался несколько раз подряд, программа сделала паузу и через N секунд попробует снова. |

### Остановка

Совсем остановить показ можно так:

- кнопкой «Остановить» или «Остановить все» в панели управления;
- прямо на экране: клавишей Esc, «-», Ctrl+Break или пунктом «Завершить показ» в меню правой кнопки мыши (если стоит галочка «Esc в показе останавливает его»);
- закрыв PowerPoint: остановятся все показы.

### Автоматический перезапуск

Если окно показа закрылось само (сбой, вмешательство другой программы), показ запускается заново с того же слайда. Если за минуту это случилось пять раз, программа ставит показ на паузу на 60 секунд, а потом пробует снова. Кнопка «Перезапустить» пробует сразу.

## 8. Экраны без присмотра

Если компьютер с расписанием стоит в холле и к нему никто не подходит:

- Снимите в панели управления галочку «Esc в показе останавливает его». Случайно нажатый Esc тогда не погасит экран: показ вернётся через несколько секунд.
- Запретите Windows гасить экран и уходить в сон. Windows 11: «Параметры» → «Система» → «Питание» (на ноутбуке «Питание и батарея») → «Экран и спящий режим». Windows 10: «Параметры» → «Система» → «Питание и спящий режим». Везде выберите «Никогда».
- Отключите заставку: «Параметры» → «Персонализация» → «Экран блокировки» → «Заставка», в списке выберите «(нет)».
- Учтите, что Windows может перезагрузиться для обновлений. После перезагрузки показы нужно запустить заново: автоматического запуска пока нет.

## 9. Обновление и удаление

**Обновление.** Закройте PowerPoint и запустите установщик новой версии. Он увидит установленную программу и предложит «Обновить до версии … или переустановить». Нажмите «Далее».

**Удаление** — любой способ:

- снова запустите установщик и выберите «Удалить Полиэкран с этого компьютера»;
- Windows 11: «Параметры» → «Приложения» → «Установленные приложения» → «⋯» рядом с «Полиэкран» → «Удалить»;
- Windows 10: «Параметры» → «Приложения» → «Приложения и возможности» → «Полиэкран» → «Удалить».

PowerPoint перед удалением нужно закрыть. Удаляются файлы программы, записи в реестре и журнал.

Для администраторов: тихая установка `Poliekran-1.4.0-setup.exe /S`, тихое удаление `Poliekran-1.4.0-setup.exe /uninstall /S`. Коды выхода: 0 — успех, 3 — запущен PowerPoint, 4 — нет .NET Framework 4.6.2, 5 — в пути к папке пользователя есть символ # или %.

## 10. Если что-то не работает

**Нет кнопки «Полиэкран» на ленте.**
«Файл» → «Параметры» → «Надстройки». Внизу в поле «Управление» выберите «Надстройки COM», нажмите «Перейти» и поставьте галочку у «Полиэкран». Если надстройки в этом списке нет, выберите в поле «Управление» пункт «Отключенные объекты», нажмите «Перейти», выделите «Полиэкран», нажмите «Включить» и перезапустите PowerPoint.

**PowerPoint спросил «Отключить надстройку?».**
Нажмите «Нет» и пришлите журнал (см. ниже).

**Показ открылся не на том мониторе.**
Нажмите «Обновить мониторы», выберите экран заново, остановите показ и запустите снова.

**Расписание не обновляется.**
Проверьте, что при запуске стояла галочка «Перезапускать показ, когда файл изменился» (в колонке «Настройки» должно быть «следит за файлом») и что сохраняют тот же файл, который запущен, а не копию с другим именем. Если файл лежит в сетевой папке, проверьте, что она доступна с этого компьютера.

**Слайды не листаются.**
В колонке «Настройки» стоит «не листать», а у слайдов нет собственного времени смены. Остановите показ и запустите снова с интервалом, например 15 с.

**Установщик пишет, что PowerPoint ещё работает.**
Закройте все окна PowerPoint. Если сообщение не пропадает, PowerPoint завис в фоне: откройте диспетчер задач (Ctrl+Shift+Esc), найдите «Microsoft PowerPoint», нажмите «Снять задачу» и затем «Повторить».

**Не запускайте PowerPoint от имени администратора.** В таком режиме он может не видеть надстройку.

### Журнал

Программа пишет журнал в `%LOCALAPPDATA%\Poliekran\log.txt`. Чтобы его найти, вставьте этот путь в адресную строку Проводника. Журнал очищается, когда перерастает 1 МБ.

Если нужна помощь, приложите журнал, укажите версии Windows и Office и опишите, что происходило. В журнале есть полные пути к вашим файлам, так что уберите из него лишнее, прежде чем отправлять.
