Полиэкран

Надстройка PowerPoint: разные презентации и электронные расписания на разных
мониторах одного компьютера. Показ не закрывается, когда PowerPoint теряет фокус.

Подробная инструкция: Poliekran-guide-ru.pdf в этой папке.
User guide in English: Poliekran-guide-en.pdf.

Как пользоваться
1. PowerPoint -> вкладка «Слайд-шоу» -> кнопка «Полиэкран». Откроется панель управления.
2. Выбрать монитор и режим (полный экран или окно).
3. Выбрать, через сколько листать слайды без своего времени смены,
   и нужно ли перезапускать показ, когда файл изменился.
4. Нажать «Запустить файл…» и выбрать презентацию.
5. Повторить для остальных мониторов.

Показ идёт по кругу. Если файл расписания пересохранили, надстройка откроет
новую версию сама, обычно в пределах 10 секунд. Показ идёт по временной копии,
поэтому оригинал можно перезаписывать во время показа.
По умолчанию слайды без своего времени смены листаются через 15 секунд.
Для обычного доклада выберите «не листать».

Esc, «-», Ctrl+Break или «Завершить показ» в самом показе останавливают его.
Для экранов без присмотра снимите галочку «Esc в показе останавливает его»:
тогда остановить показ можно только кнопками «Остановить» и «Остановить все».

Если окно показа закрылось само, показ перезапустится с того же слайда.
После пяти перезапусков за минуту он получит статус «упал» и через 60 секунд
попробует снова. Кнопка «Перезапустить» пробует сразу.

Если кнопки нет
Файл -> Параметры -> Надстройки -> Управление: Надстройки COM -> Перейти.
Поставить галочку у «Полиэкран». Если надстройки там нет: Управление:
Отключенные объекты -> Перейти -> выделить «Полиэкран» -> Включить.
Не запускайте PowerPoint от имени администратора.

Журнал
%LOCALAPPDATA%\Poliekran\log.txt (вставить в адресную строку Проводника).

Удаление
Запустить установщик ещё раз и выбрать «Удалить»,
или Параметры Windows -> Приложения -> Полиэкран -> Удалить.
